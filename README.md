# Gym Tracker updates

Signed over-the-air updates for the Gym Tracker Android app. The app only uses these files if
`manifest.sig` matches the publisher's key and every file matches its SHA-256 in `manifest.txt`.

Food data: Open Food Facts (Open Database Licence), McCance & Widdowson CoFID 2021 (Crown copyright,
Open Government Licence). Scanner: ZXing (Apache 2.0).
